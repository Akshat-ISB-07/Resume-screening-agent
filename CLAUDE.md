# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

Resume screening agent: upload PDFs, define weighted criteria, and get Claude AI to evaluate and bucket candidates into **Strong Hire / Promising / Needs Review / Not Suitable**.

## Running

```bash
./run.sh                          # from project root (uses .venv)
# or manually:
cd backend
../.venv/bin/uvicorn main:app --reload --port 8000
```

Then open `frontend/index.html` directly in a browser.

## Architecture

### Backend (`backend/`)

| File | Role |
|---|---|
| `main.py` | FastAPI server — job lifecycle API |
| `claude_evaluator.py` | Claude API calls; computes weighted score and bucket in Python |
| `pdf_extractor.py` | PDF → plain text via pdfplumber |

**Job lifecycle API** (all in-memory, no database):

```
POST /jobs          → create job (title, description, criteria[])
POST /upload/{id}   → upload one or more PDF files (multipart)
POST /run/{id}      → kick off background thread that evaluates each resume sequentially
GET  /status/{id}   → poll for progress (0-100%), progress_message, and results[]
GET  /health        → {"status":"ok"}
```

**Evaluation flow** (`_run_evaluations` thread in `main.py`):
- For each resume, calls `evaluate_resume_for_job()` in `claude_evaluator.py`
- Claude returns per-criterion scores (0–100); Python computes the weighted average
- Bucket thresholds: Strong Hire ≥80 · Promising ≥60 · Needs Review ≥40 · Not Suitable <40
- Results accumulate in `_jobs[id]["results"]` as they complete

**Key details:**
- Model: `claude-sonnet-4-6`
- Resume text is truncated to 8 000 chars before sending to Claude
- Claude is prompted to return only JSON; response is parsed directly with `json.loads`
- The in-memory `_jobs` dict is reset on server restart

### Frontend (`frontend/index.html`)

Single-page app with three phases driven by JS state:

1. **Setup form** — job title, description, 5 default criteria (editable name + weight), multi-PDF drag-and-drop (up to 100 files). Submit button stays disabled until weights sum to 100%.
2. **Progress view** — shown immediately after `POST /run/{id}`; polls `GET /status/{id}` every 3 seconds, updates progress bar and `progress_message`.
3. **Results view** — 4-column bucket grid. Each candidate card is clickable to expand strengths, gaps, per-criterion scores, and 3 tailored screening questions.

Default criteria pre-filled: Product Strategy (25%), Technical Depth (20%), Leadership & Execution (20%), Data & Analytics (20%), Communication (15%).

## Environment

`backend/.env` must contain:
```
ANTHROPIC_API_KEY=sk-...
```

## Dependencies

Virtual environment at `.venv/` (Python 3.14). Key packages: `fastapi`, `uvicorn`, `anthropic`, `pdfplumber`, `python-multipart`, `fpdf2`. Install or update with:
```bash
pip install -r backend/requirements.txt
```
